Castle Daily — a daily risk tracker for companies.

Five screens covering the loop a customer would run every morning: onboard once → daily home each morning → drill into changing exposures → clear an inbox of items needing action → confirm a recommended hedge.

All mocks share a single fictional customer (Cardinal Renewable Partners) and the live data from the brief. The point is to see the product end-to-end before building it.
